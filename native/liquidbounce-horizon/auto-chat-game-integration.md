# AutoChatGame integration

Pinned LiquidBounce ae0eb396 and its AiChatClient/service wire formats. Both transactional integrators (`integrate-auto-chat-game.py --apply` and `integrate-auto-chat-game-wake.py --apply`) and the locale updater have been applied by root. All twelve source settings are present. The 900-character default prompt is extracted from the pinned Kotlin source and embedded as Rust source so source packages include it.

The existing real SystemChat/GAME_MESSAGE hook supplies original text; player and disguised chat never enter this module. Strict source chronometers, ASCII Java regex whitespace collapse plus Kotlin trim, IncludeTrigger, cooldown, independent concurrent GG delays, one pending question continuation and current-at-send Java AnswerTemplate formatting are preserved. Disabling cancels pending output and keeps the source's buffer/chronometer lifetime. Blank-key enable errors, question/answer/delay status and failures follow the game's Simplified or Traditional Chinese language.

HTTP runs on a background worker using the existing pinned ureq stack, with 10-second connect and 20-second read/write timeouts. OpenAI-compatible and Anthropic roots, URL resolution, authentication, request bodies, text-block response handling, trailing-dot removal and provider errors match the pinned service declarations. Keys and transport URLs are excluded from error logs. A separate idle-loop deadline keeps delayed output and worker completion polling independent of game speed; only the question buffer's tickUntil advances on GameTick. A disabled generation drops its receiver and cannot emit an old answer; a transport already inside a blocking ureq operation may finish until its timeout.

Private local settings retain the key like the original file config. Public AutoConfig's `doNotIncludeAlways` exclusion must be consumed when the still-unimplemented AutoConfig service is connected; public export parity is not claimed here.

The prepared batch harness covers strict buffering/cooldown/GG/cancel behavior, actual loopback HTTP for both protocols, JSON framing and provider errors, secret redaction, Java formatting and all twelve settings in File/Interop round trips. It sends no third-party requests. Static patch/locale/AST evidence is in `build/auto-chat-game-static-01/report.json`. Official compilation and the focused harness are deferred to the next multi-module batch as requested. No full suite or game run has been performed.
