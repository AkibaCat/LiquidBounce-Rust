# XRay integration

Pinned LiquidBounce `ae0eb396c07f22383789b28d5912d714c6ca0a86`. XRay has the original four settings, registry-backed block commands, English and both Chinese locales. Its generated defaults preserve the difference between first initialization (78 source defaults plus 32 family entries) and command reset (the 78 defaults).

The actual section mesher consumes one immutable policy snapshot per build. It tests the six real neighboring block conductor flags for ExposedOnly, preserves face visibility semantics and moves background model vertices to the existing translucent pass with their configured opacity. The original 24-byte vertex format is retained. Terrain, OIT and world warp shaders consume that opacity. FullBright suppresses model ambient occlusion and supplies the original maximum gamma, preserving the FullBright module's existing priority. Resource reloads rebuild loaded sections on changes. Horizon's extra far terrain is suspended while XRay runs.

`integrate-xray.py --apply` and `update-xray-locales.py` have already been applied. Do not repeat the non-idempotent integrator. `xray-patch.py` is composed after earlier native extensions and before Step. It also explicitly reexports the render policy through the split client library.

The single successful focused check is `build/xray-smoke-02/report.json`: production behavior and config roundtrips, immutable snapshots, opacity migration, native patch composition and Naga validation of the actual terrain and OIT WGSL. The first attempt failed in its test fixture before execution. Official Check161-01 found the missing split-library reexport. That call was corrected. Native and engine compilation passed in `build/check-native-161-04.log`, with official report `build/integrated-check-161-04.json`.
